# Expense Tracker

A responsive Expense Tracker built with React and Vite. It helps users manage their income and expenses, review their balance, and organize transactions.

## Features

- Dashboard showing balance, income, and expenses
- Add income and expense transactions
- Select a transaction category and date
- Delete transactions
- Search transactions
- Filter transactions
- Save data using Local Storage
- Responsive dashboard design

## Technologies Used

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Browser Local Storage

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd expense-tracker
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.
